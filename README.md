# HardwareXT para escritorio

La web de [HardwareXT](https://www.hardwarext.com) dentro de una app: guías,
aplicaciones, gaming y seguridad, que se leen también **sin conexión** y se
ponen al día solas.

Aquí solo se publican los instaladores. Están en
**[Releases](https://github.com/HardwareXT/HardwareXT-Descargas/releases/latest)**:

| Sistema | Fichero |
|---|---|
| Windows 10 y 11 | `…_x64-setup.exe` |
| Linux (cualquier distribución) | `….AppImage` |
| Debian, Ubuntu, Linux Mint | `….deb` |
| Fedora, openSUSE | `….rpm` |

Las instrucciones de instalación están en https://www.hardwarext.com.

**Descárgala solo desde aquí o desde la web oficial.** La app es gratuita y no
está firmada, así que Windows puede enseñar el aviso de SmartScreen («Windows
protegió su PC»): pulsa «Más información» y luego «Ejecutar de todas formas».
